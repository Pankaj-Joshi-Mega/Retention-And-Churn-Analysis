# 📊 Customer Churn & CLV Analysis Dashboard | Power BI

## 📌 Project Overview

This Power BI project analyzes customer churn, retention, loyalty programs, and Customer Lifetime Value (CLV) to help businesses understand customer behavior and improve decision-making. The dashboard provides actionable insights into customer engagement, repeat purchases, promotion effectiveness, and overall business performance.

## 🎯 Objectives

* Analyze customer churn and retention trends.
* Identify high-value and repeat customers.
* Measure Customer Lifetime Value (CLV).
* Evaluate loyalty program effectiveness.
* Assess the impact of promotions on sales.
* Compare store and online channel performance.

## 📈 Key Features

* Customer Churn Analysis
* Retention Rate Tracking
* Repeat Purchase Analysis
* Customer Lifetime Value (CLV) Dashboard
* Loyalty Program Insights
* Promotion Impact Analysis
* Customer Segmentation
* Interactive Power BI Visualizations

## 📊 KPIs Monitored

* Churn Rate
* Retention Rate
* Total Customers
* Repeat Customers
* Customer Lifetime Value (CLV)
* Average Purchase Frequency
* Average Transaction Amount
* Loyal Customer Count

## 💡 Key Insights

* High customer churn highlights the need for stronger retention strategies.
* Mid-tier customers contribute the highest share of customer value.
* Repeat customers generate more consistent revenue.
* Online channels experience higher churn than physical stores.
* Loyalty programs have potential for increased customer engagement.

This project demonstrates how customer analytics can help organizations reduce churn, improve retention, optimize marketing efforts, and maximize customer lifetime value through data-driven decision-making.
